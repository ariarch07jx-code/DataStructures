# 1.1 串的定义与存储

## 一、定义

串（String）是由**零个或多个字符**组成的有限序列：

```
S = "a1 a2 ... an"
```

- 串长 n；n = 0 时是**空串**。
- 字符在串中的位置从 **1** 开始。

## 二、易混概念

- **空串 `""`**：长度为 0，一个字符都没有。
- **空格串 `" "`**：由空格组成，长度 ≥ 1。空格也是字符，别把空格串当空串。
- **子串**：串中任意个**连续**字符组成的子序列。例如 `"abc"` 的子串有 `""`、`"a"`、`"ab"`、`"abc"`、`"b"`、`"bc"`、`"c"`。

## 三、存储结构

### 1. 定长顺序存储

用固定长度的数组存字符，一般用 `ch[0]` 存串长（字符从下标 1 开始放）：

```c
#define MAXLEN 255

typedef struct {
    char ch[MAXLEN + 1];  // ch[0] 存串长，ch[1..MAXLEN] 存字符
} SString;
```

- 优点：随机存取、实现简单。
- 缺点：长度固定，超长会被**截断**。

> 另一种约定是下标从 0 开始、末尾放 `'\0'`，也就是 C 语言 `char[]` 的方式。**两种约定别混**，本笔记的算法代码统一用「`ch[0]` 存长度、下标从 1 开始」的严蔚敏写法。

### 2. 堆分配存储（堆串）

用 `malloc` 动态分配，长度可变化，实际中最实用：

```c
typedef struct {
    char *ch;    // 指向动态分配的字符数组
    int length;  // 串长
} HString;
```

- 优点：长度灵活，不会截断。
- 缺点：需要手动 `malloc` / `free`。

### 3. 块链存储

每个结点存多个字符（一个「块」），减少指针占用的比例：

```c
#define CHUNKSIZE 4  // 每个结点存 4 个字符

typedef struct Chunk {
    char ch[CHUNKSIZE];
    struct Chunk *next;
} Chunk;
```

- 优点：插入删除灵活。
- 缺点：操作麻烦，**存储密度**（字符占的空间比例）低，实际很少用。

## 四、基本操作

| 操作 | 含义 |
|---|---|
| `StrAssign` | 赋值 |
| `StrLength` | 求长度 |
| `StrCompare` | 比较两个串 |
| `StrCopy` | 复制 |
| `Concat` | 连接 |
| `SubString` | 求子串 |
| `Index` | 定位（找子串第一次出现的位置） |

其中 `Index`（定位）就是**模式匹配**，是下一节 [1.2 模式匹配](1.2_PatternMatch.md) 的主角。

## 五、C 语言的字符串（实际中用这个）

C 里字符串就是 `char` 数组，末尾自动补 `'\0'` 表示结束：

```c
char s[] = "abc";   // 实际是 {'a','b','c','\0'}，占 4 字节
strlen(s);          // 返回 3，不含 '\0'
```

常用函数在 `<string.h>`：`strlen`（长度）、`strcpy`（复制）、`strcmp`（比较）、`strcat`（连接）。

> 笔记里的算法代码用「`ch[0]` 存长度」是为了和教材一致、方便说明下标；真正写代码时直接用 C 的 `'\0'` 结尾字符串 + `<string.h>` 更省事。
