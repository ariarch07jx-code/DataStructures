# 03 串 (String)

串（字符串）是**零个或多个字符组成的有限序列**，可以看成「数据元素限定为字符」的线性表。

## 一、基本术语

| 术语 | 含义 |
|---|---|
| 串 | 字符的有限序列，如 `S = "hello"` |
| 串长 | 串中字符的个数 |
| 空串 | 长度为零的串，记作 `""` |
| 空格串 | 由一个或多个空格组成，长度不为零，别和空串混 |
| 子串 | 串中任意个**连续**字符组成的子序列 |
| 主串 | 包含子串的串 |
| 位置 | 字符在串中的序号（从 1 开始） |
| 串相等 | 长度相等，且对应位置的字符都相同 |

## 二、串 vs 线性表

串是特殊的线性表：数据元素限定为**字符**。但串的**操作对象往往是子串**（一段连续字符），而不是单个元素，所以它的存储和操作有自己的特点。

## 三、存储结构

| | 定长顺序 | 堆分配（堆串） | 块链 |
|---|---|---|---|
| 实现 | 固定数组 | 动态 `malloc` | 结点里存多个字符 |
| 长度 | 固定，超长会截断 | 可变 | 可变 |
| 特点 | 简单 | 最常用 | 存储密度高，操作麻烦 |

## 四、核心：模式匹配

求「模式串在主串中**第一次出现的位置**」，是串最重要的算法：

- **BF（朴素）**：暴力逐个比，最坏 O(n·m)。
- **KMP**：利用已匹配的信息让主串指针不回溯，O(n+m)。

## 五、复杂度速查

| 算法 | 时间复杂度 |
|---|---|
| BF 朴素匹配 | O(n·m)（最坏） |
| 求 next 数组 | O(m) |
| KMP 匹配 | O(n+m) |
