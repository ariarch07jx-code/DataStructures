# 1.3 广义表

## 一、定义

**广义表**是线性表的推广：元素既可以是**原子**（单个数据），也可以是**子表**（另一个广义表）。

```
LS = (a1, a2, ..., an)
```

### 例子

| 广义表 | 说明 |
|---|---|
| `A = ()` | 空表，长度 0 |
| `B = (e)` | 长度 1，只有一个原子 e |
| `C = (a, (b, c, d))` | 长度 2：原子 a + 子表 (b,c,d) |
| `D = (A, B, C)` | 长度 3：三个子表 |
| `E = (a, E)` | 长度 2，**递归表**（自己包含自己，无限展开） |

## 二、核心术语

- **表头 (Head)**：第一个元素，可以是原子，也可以是子表。
- **表尾 (Tail)**：除表头外的**其余元素组成的表**——**一定是表**（哪怕只有一个元素，也要套一层括号）。
- **长度**：最外层元素的个数。
- **深度**：括号的最大嵌套层数（递归定义）。

### 例：`C = (a, (b, c, d))`

- 表头 = `a`（原子）
- 表尾 = `((b, c, d))`（注意：是「表」，比 `(b,c,d)` 多一层括号）
- 长度 = 2
- 深度 = 2

> **易错点**：表尾 = `((b,c,d))`，不是 `(b,c,d)`。表尾永远是一个**广义表**，所以要在剩余元素外面再套一层括号。

## 三、三个重要特点

1. **可递归**：`E = (a, E)`，元素可以是它自己。
2. **可共享**：一个子表可以被多个表引用（用指针指向同一个表，不复制）。
3. **可以是空表**：`A = ()`。

这三点是广义表和普通线性表最大的区别，也是它难在**用指针实现**的原因。

## 四、存储结构

### 1. 头尾链表存储法

结点分两类，用 `tag` 区分：

- `tag = 0`（ATOM）原子结点：存值。
- `tag = 1`（LIST）表结点：存表头指针 `hp` 和表尾指针 `tp`。

```c
typedef enum { ATOM, LIST } ElemTag;   // ATOM=0 原子，LIST=1 子表

typedef struct GLNode {
    ElemTag tag;            // 区分原子 / 表
    union {
        ElemType value;     // 原子结点：存值
        struct {            // 表结点：表头 + 表尾
            struct GLNode *hp;   // 指向表头
            struct GLNode *tp;   // 指向表尾（下一个元素组成的表）
        } ptr;
    };
} GLNode;
```

- 任何一个广义表都能拆成「表头 + 表尾」，递归下去，所以用「头尾」两个指针就能表示全部结构。
- `union`（共用体）让同一块空间在原子结点存值、在表结点存两个指针，省空间。

### 2. 扩展线性表存储法

不管原子还是子表，每个结点都带一个 `next` 指针指向「下一个元素」，像普通链表一样平铺。实现更直观，但表达「表尾」不如头尾法自然。

## 五、基本操作

| 操作 | 含义 |
|---|---|
| `Head(L)` | 取表头（第一个元素） |
| `Tail(L)` | 取表尾（去掉表头后剩下的表） |
| `Length(L)` | 求长度（最外层元素个数） |
| `Depth(L)` | 求深度 |

## 六、求深度（重点，递归）

深度递归定义：

- 空表深度 = 1，原子深度 = 0。
- 一般表深度 = **所有子表深度的最大值 + 1**。

```c
int GListDepth(GLNode *L) {
    if (L == NULL) return 1;          // 空表
    if (L->tag == ATOM) return 0;     // 原子

    int max = 0;
    GLNode *p = L;
    while (p != NULL) {
        int d = GListDepth(p->ptr.hp);  // 递归求每个子表深度
        if (d > max) max = d;
        p = p->ptr.tp;                  // 走表尾，看下一个元素
    }
    return max + 1;
}
```

## 七、易错点汇总

1. **表尾多一层括号**：`C = (a, (b,c,d))` 的表尾是 `((b,c,d))`，不是 `(b,c,d)`。
2. **深度 vs 长度**：长度数「最外层几个元素」，深度数「括号最多套几层」。
3. **空表深度是 1，原子深度是 0**——递归求深度的两个基准别写反。
4. `Head` 和 `Tail` 一对操作：任何广义表都可写成 `L = (Head(L), ... Tail 里的元素)`，这是递归处理广义表的通用思路。
