# 1.1 数组与特殊矩阵

## 一、数组的定义与特点

**数组**：由**相同类型**数据元素组成的、每个元素受 n 个线性关系约束的集合，即 n 维数组。

- 数组是线性表的推广：**n 维数组 = 数据元素为 (n-1) 维数组的线性表**。
- **特点**：一旦定义，**维数和维界就固定**，基本操作只有「**存取元素**」和「**修改元素**」，**不做插入删除**。
- 因为结构固定，所以数组一律用**顺序存储**（连续空间），元素的地址可以**用公式算出来**——这就是「随机存取」。

## 二、地址计算（重点）

假设每个元素占 L 个字节，`LOC(a0)` 是首地址。

### 一维数组

```
LOC(ai) = LOC(a0) + i × L
```

### 二维数组（行优先，C 语言用这个）

m 行 n 列，`a[i][j]`（i 行 j 列，下标从 0 开始）：

```
LOC(a[i][j]) = LOC(a[0][0]) + (i × n + j) × L
```

### 二维数组（列优先）

```
LOC(a[i][j]) = LOC(a[0][0]) + (j × m + i) × L
```

### 关键点

- **行优先**：先按行排满，同一行的元素连续。
- **列优先**：先按列排满，同一列的元素连续。
- C / C++ 是**行优先**，Fortran / MATLAB 是**列优先**，做题先看清语言约定。

## 三、特殊矩阵的压缩存储

**目的**：矩阵里值有规律、有很多重复或零元素时，只存有用的部分，节省空间。

### 1. 对称矩阵

满足 `a[i][j] == a[j][i]`。只存**下三角（含主对角线）**，共 `n(n+1)/2` 个元素，存进一维数组 `B[0 .. n(n+1)/2 - 1]`。

下标从 **1** 开始（i、j 从 1 起），k 从 **0** 开始：

```
下三角（i ≥ j）：k = i(i-1)/2 + j - 1
上三角（i <  j）：先转成 a[j][i]，再用上式计算
```

> 例：`a[4][2]`（下三角）→ k = 4×3/2 + 2 − 1 = 7，存在 B[7]。

### 2. 三角矩阵

上三角（或下三角）全是一个**常数 c**（通常是 0）。只存下（上）三角 + 一个常数，共 `n(n+1)/2 + 1` 个元素，**最后一个位置存常数 c**。

```
下三角矩阵：存下三角元素 + B[n(n+1)/2] 存上三角的常数 c
上三角矩阵：存上三角元素 + B[n(n+1)/2] 存下三角的常数 c
```

### 3. 对角矩阵（三对角）

只有**主对角线及其上下各一条对角线**上有非零元素，其余全为 0。共 `3n − 2` 个非零元素。

下标从 1 开始、k 从 0 开始，按行优先存三条对角线：

```
k = 2(i − 1) + (j − 1) = 2i + j − 3   （i、j 从 1 起）
```

> 三对角的特点：`|i − j| ≤ 1` 时才有非零元素，其余为 0。

## 四、小结表格

| 矩阵类型 | 存多少元素 | 压缩依据 |
|---|---|---|
| 对称矩阵 | n(n+1)/2 | a[i][j] = a[j][i] |
| 三角矩阵 | n(n+1)/2 + 1 | 一半是常数 |
| 三对角矩阵 | 3n − 2 | 只有三条对角线上有值 |

## 五、易错点

1. **下标约定别混**：地址公式里 i、j 一般从 **0** 开始（C 风格），压缩存储公式里 i、j 常从 **1** 开始（教材风格）。两个公式不能直接混用。
2. 对称矩阵访问上三角元素时，**要先 `a[i][j] = a[j][i]` 换一下**再套下三角公式。
3. 三角矩阵比对称矩阵**多存 1 个元素**（那个常数），别漏。
