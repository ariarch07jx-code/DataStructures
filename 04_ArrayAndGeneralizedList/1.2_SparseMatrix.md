# 1.2 稀疏矩阵

## 一、定义

**稀疏矩阵**：非零元素**远少于**零元素，且**分布没有规律**的矩阵。

> 和 1.1 的特殊矩阵区别：特殊矩阵的非零元素分布**有规律**（对称、三角…），稀疏矩阵分布**无规律**，只能把每个非零元素连同行列位置一起存下来。

## 二、三元组表示法

只存非零元素，每个元素记成 `(行, 列, 值)` 三元组。

```c
#define MAXSIZE 100

typedef int ElemType;

typedef struct {
    int row, col;   // 行号、列号
    ElemType value; // 值
} Triple;

typedef struct {
    Triple data[MAXSIZE + 1];  // 存三元组，data[0] 一般不用
    int rows, cols, nums;      // 总行数、总列数、非零元素个数
} TSMatrix;
```

一个 6×7、有 8 个非零元素的矩阵，存成三元组表后只要 8 个 `(row, col, value)` 记录。

## 三、转置（重点）

### 1. 普通转置

按**原矩阵的列**从 1 扫到 cols，每扫一列就把该列的所有非零元素逐个放进新表。因为转置后"原矩阵第 col 列"变成"新矩阵第 col 行"。

```c
void Transpose(TSMatrix M, TSMatrix *T) {
    T->rows = M.cols;
    T->cols = M.rows;
    T->nums = M.nums;
    if (M.nums == 0) return;

    int q = 1;                          // 新表的下标
    for (int col = 1; col <= M.cols; col++) {       // 逐列扫描原矩阵
        for (int p = 1; p <= M.nums; p++) {         // 找这一列的所有非零元素
            if (M.data[p].col == col) {
                T->data[q].row = M.data[p].col;
                T->data[q].col = M.data[p].row;
                T->data[q].value = M.data[p].value;
                q++;
            }
        }
    }
}
```

- 复杂度：**O(cols × nums)**。最坏（nums 接近 cols×rows 时）退化成 O(cols²×rows)。

### 2. 快速转置（O(cols + nums)）

普通转置慢在「一遍遍扫全表找某一列」。快速转置改成：**先统计每列有多少非零元素，算出每列在新表中的起始位置**，然后一遍扫描把每个元素直接放到正确位置。

两个辅助数组：

- `num[col]`：第 col 列的非零元素个数。
- `cpot[col]`：第 col 列第一个非零元素在新表中的位置。

```
cpot[1] = 1
cpot[col] = cpot[col-1] + num[col-1]   （col ≥ 2）
```

```c
void FastTranspose(TSMatrix M, TSMatrix *T) {
    T->rows = M.cols;
    T->cols = M.rows;
    T->nums = M.nums;
    if (M.nums == 0) return;

    int num[M.cols + 1], cpot[M.cols + 1];
    for (int col = 1; col <= M.cols; col++) num[col] = 0;

    for (int p = 1; p <= M.nums; p++)       // 统计每列个数
        num[M.data[p].col]++;

    cpot[1] = 1;                            // 算每列起始位置
    for (int col = 2; col <= M.cols; col++)
        cpot[col] = cpot[col - 1] + num[col - 1];

    for (int p = 1; p <= M.nums; p++) {     // 一遍扫描，直接放到位
        int col = M.data[p].col;
        int q = cpot[col];                  // 该列当前该放的位置
        T->data[q].row = M.data[p].col;
        T->data[q].col = M.data[p].row;
        T->data[q].value = M.data[p].value;
        cpot[col]++;                        // 该列下一个元素放后一格
    }
}
```

- 复杂度：**O(cols + nums)**。

## 四、十字链表（链式存储）

三元组表适合「整体存取」，但做矩阵加法等**需要频繁插入删除**时，顺序表移动元素很麻烦。十字链表用**行、列两条链**把非零元素串起来。

```c
typedef struct OLNode {
    int row, col;
    ElemType value;
    struct OLNode *right;  // 指向同一行下一个非零元素
    struct OLNode *down;   // 指向同一列下一个非零元素
} OLNode;

typedef struct {
    OLNode *rowHead[MAXSIZE];  // 每行的头指针
    OLNode *colHead[MAXSIZE];  // 每列的头指针
    int rows, cols, nums;
} CrossList;
```

- 每个非零元素结点同时挂在**行链**和**列链**上，像十字交叉。
- 适合：稀疏矩阵**相加**这类要「在行/列上动态增删结点」的操作。

## 五、复杂度速查

| 操作 | 复杂度 |
|---|---|
| 普通转置 | O(cols × nums) |
| 快速转置 | O(cols + nums) |

## 六、易错点

1. `cpot[col]++` 那一步别漏——它保证**同一列**的多个非零元素依次排开，否则会互相覆盖。
2. `cpot` 的递推 `cpot[col] = cpot[col-1] + num[col-1]` 里是 `num[col-1]`（上一列的个数），不是 `num[col]`。
3. 三元组表 `data[0]` 一般**空着不用**（从下标 1 存），循环也从 1 开始，别从 0 开始。
