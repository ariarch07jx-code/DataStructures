# 04 数组和广义表 (Array & Generalized List)

数组可以看成线性表的**推广**：线性表的元素是原子，数组的元素可以是另一个数组。广义表又是数组（线性表）的进一步推广——元素可以是原子，也可以是子表。

## 一、本章结构

| 内容 | 核心 |
|---|---|
| 数组 | 顺序存储 + **地址计算公式** |
| 特殊矩阵 | 利用规律**压缩存储**（对称 / 三角 / 对角） |
| 稀疏矩阵 | 只存非零元素（三元组 / 十字链表） |
| 广义表 | 元素可以是子表，**递归 / 共享** |

## 二、为什么有这一章

数组本身没什么好说的（就是连续存储 + 下标公式），这一章真正的重点是：

1. **地址计算**——知道下标，直接算出元素在内存的地址（随机存取的原理）。
2. **压缩存储**——矩阵非零元素少时，怎么省空间。
3. **广义表的递归结构**——为后面「树、图」的递归思想做铺垫。

## 三、复杂度速查

| 操作 | 复杂度 |
|---|---|
| 数组按下标存取 | O(1) |
| 稀疏矩阵普通转置 | O(cols × nums) |
| 稀疏矩阵快速转置 | O(cols + nums) |
| 求广义表深度 | O(长度)（递归） |
