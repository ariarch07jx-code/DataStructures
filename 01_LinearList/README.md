# 01 线性表 (Linear List)

线性表是「n 个具有**相同数据类型**的数据元素的**有限序列**」，是最基础、最常用的线性结构。

## 一、逻辑结构

- **表长**：元素个数 n；n = 0 时为**空表**。
- **位序**：元素在线性表中的位置，从 **1** 开始（数组下标从 **0** 开始，两者差 1）。
- **前驱 / 后继**：
  - 除第一个元素（表头）外，每个元素**有且仅有**一个直接前驱；
  - 除最后一个元素（表尾）外，每个元素**有且仅有**一个直接后继。
- 特点：元素之间是「一对一」的线性关系。

## 二、逻辑结构 vs 存储结构

> 线性表的**逻辑结构只有一种**，但**存储结构有多种**。学的时候要分清「逻辑」和「存储」。

| | 顺序存储（顺序表） | 链式存储（链表） |
|---|---|---|
| 物理存储 | 连续空间，逻辑相邻即物理相邻 | 任意空间，用指针链接 |
| 访问方式 | **随机存取**（按位 O(1)） | 顺序存取（按位 O(n)） |
| 实现 | 数组 | 结点 + 指针 |

## 三、复杂度速查

| 操作 | 顺序表 | 单链表 | 双链表 |
|---|---|---|---|
| 按位查找 GetElem | O(1) | O(n) | O(n) |
| 按值查找 LocateElem | O(n) | O(n) | O(n) |
| 插入（按位序） | O(n)（移动元素） | O(n)（遍历） | O(n) |
| 删除（按位序） | O(n)（移动元素） | O(n) | O(n) |
| 已知结点后插 | — | O(1) | O(1) |
| 删除已知结点 | — | O(n)（或偷梁换柱 O(1)） | O(1) |
