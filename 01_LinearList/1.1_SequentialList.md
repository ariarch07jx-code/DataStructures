# 1.1 顺序表 (Sequential List)

用**一段地址连续的存储单元**依次存储数据元素，使逻辑上相邻的元素**物理上也相邻**，底层用**数组**实现。

## 一、存储结构

```c
#define MAXSIZE 100

typedef int ElemType;

typedef struct {
    ElemType data[MAXSIZE];  // 存储元素
    int length;              // 当前表长（实际元素个数）
} SeqList;
```

- `length` 是**当前元素个数**，不是数组容量 `MAXSIZE`。
- 静态分配固定容量 `MAXSIZE`；满了不能再插，需 `realloc` 扩容（代码里未实现）。

## 二、位序 vs 下标（高频易错点）

- 逻辑**位序 pos 从 1 开始**，数组**下标从 0 开始**。
- 第 pos 个元素 → 数组下标 `pos - 1`。
- 所有边界判断都要想清楚这一层「差 1」。

## 三、基本操作（代码实现）

| 操作 | 说明 | 时间复杂度 |
|---|---|---|
| InitList(L) | 初始化，length = 0 | O(1) |
| appendElem(L, e) | 尾部追加元素 e | O(1) |
| insertElem(L, pos, e) | 在第 pos 位插入 e | O(n)（移动元素） |
| deleteElem(L, pos) | 删除第 pos 位元素 | O(n)（移动元素） |
| findElem(L, e) | 按值查找，返回位序（从 1 开始），未找到返回 -1 | O(n) |
| traverseList(L) | 遍历打印所有元素 | O(n) |

## 四、尾部追加 appendElem（核心之一）

在表尾追加元素，等价于在第 `length+1` 位插入：

```c
int appendElem(SeqList *L, ElemType e) {
    if (L->length >= MAXSIZE) {   // 表满
        printf("List is full\n");
        return 0;
    }
    L->data[L->length] = e;        // 直接放到末尾
    L->length++;
    return 1;
}
```

## 五、插入 insertElem（核心）

在第 pos（**1 ≤ pos ≤ length+1**）位插入 e，把第 pos 个及之后的元素**从后往前**依次后移一位。

```c
int insertElem(SeqList *L, int pos, ElemType e) {
    if (pos < 1 || pos > L->length + 1) {   // 位序非法
        printf("Position is invalid\n");
        return 0;
    }
    if (L->length >= MAXSIZE) {             // 表满
        printf("List is full\n");
        return 0;
    }
    for (int i = L->length - 1; i >= pos - 1; i--)
        L->data[i + 1] = L->data[i];         // 从后往前移
    L->data[pos - 1] = e;
    L->length++;
    return 1;
}
```

- 移动次数：n − pos + 1；平均 n/2 次。
- 合法性：pos ∈ **[1, length+1]**（可以插在末尾）；表满（length == MAXSIZE）不能插。
- ⚠️ 必须从后往前移，否则前面的元素会被覆盖。

## 六、删除 deleteElem（核心）

删除第 pos（**1 ≤ pos ≤ length**）位元素，把第 pos+1 个及之后的元素**从前往后**依次前移一位。

```c
int deleteElem(SeqList *L, int pos) {
    if (pos < 1 || pos > L->length) {        // 位序非法
        printf("Position is invalid\n");
        return 0;
    }
    for (int i = pos - 1; i < L->length - 1; i++)
        L->data[i] = L->data[i + 1];         // 从前往后移
    L->length--;
    return 1;
}
```

- 移动次数：n − pos；平均 (n−1)/2 次。
- 合法性：pos ∈ **[1, length]**。
- ⚠️ 插入和删除的**移动方向相反**，这是高频易错点。

## 七、查找 findElem

按值查找第一个等于 e 的元素，返回**位序（从 1 开始）**，未找到返回 **-1**：

```c
int findElem(SeqList *L, ElemType e) {
    for (int i = 0; i < L->length; i++)
        if (L->data[i] == e)
            return i + 1;   // 下标 i 对应位序 i+1
    return -1;              // 未找到
}
```

## 八、优缺点

**优点**：支持随机存取（按位 O(1)）；存储密度高（只存数据，无指针开销）。

**缺点**：插入/删除要移动大量元素 O(n)；需要连续空间，扩容麻烦；分配过小不够用、过大浪费。
