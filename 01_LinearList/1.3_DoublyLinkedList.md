# 1.3 双链表 (Doubly Linked List)

在单链表基础上，每个结点**增加一个指向前驱的指针 prev**，可双向遍历。

## 一、结点结构

```c
typedef struct DNode {
    ElemType data;        // 数据域
    struct DNode *prev;   // 前驱指针
    struct DNode *next;   // 后继指针
} DNode;
```

## 二、初始化

```c
DNode* InitList() {
    DNode *head = (DNode*)malloc(sizeof(DNode));
    head->data = 0;
    head->prev = NULL;
    head->next = NULL;
    return head;
}
```

## 三、头插 / 尾插

**头插 insertHead**：

```c
void insertHead(DNode *L, ElemType e) {
    DNode *newNode = (DNode*)malloc(sizeof(DNode));
    newNode->data = e;
    newNode->next = L->next;
    newNode->prev = L;
    if (L->next != NULL)           // 原首结点回指 newNode
        L->next->prev = newNode;
    L->next = newNode;
}
```

**尾插 insertTail**：

```c
void insertTail(DNode *L, ElemType e) {
    DNode *newNode = (DNode*)malloc(sizeof(DNode));
    newNode->data = e;
    newNode->next = NULL;
    DNode *p = L;
    while (p->next != NULL)        // 找到尾结点
        p = p->next;
    newNode->prev = p;
    p->next = newNode;
}
```

## 四、按位插入 insertElem（核心）

在第 pos 位插入 e，先找到前驱 p，再在 p 之后插入 newNode：

```c
int insertElem(DNode *L, int pos, ElemType e) {
    if (pos < 1 || pos > MAXSIZE) {
        printf("Position is invalid\n");
        return 0;
    }
    DNode *newNode = (DNode*)malloc(sizeof(DNode));
    newNode->data = e;
    DNode *p = L;
    for (int i = 1; i < pos; i++) {   // 找前驱 p
        if (p->next == NULL) {
            printf("Position is invalid\n");
            free(newNode);
            return 0;
        }
        p = p->next;
    }
    newNode->next = p->next;
    newNode->prev = p;
    p->next = newNode;
    return 1;
}
```

⚠️ **易错点**：插在**中间位置**时，还要让原后继 `newNode->next` 的 prev 回指 newNode，否则那条 prev 指针是断的。头插 `insertHead` 里已经处理了（`if (L->next != NULL) L->next->prev = newNode;`），但 `insertElem` 里**漏了这一步**，建议补上：

```c
    if (newNode->next != NULL)
        newNode->next->prev = newNode;
```

## 五、按位删除 deleteElem（核心）

```c
int deleteElem(DNode *L, int pos) {
    if (pos < 1 || pos > MAXSIZE) {
        printf("Position is invalid\n");
        return 0;
    }
    DNode *p = L;
    for (int i = 1; i < pos; i++) {   // 找前驱 p
        if (p->next == NULL) {
            printf("Position is invalid\n");
            return 0;
        }
        p = p->next;
    }
    DNode *temp = p->next;            // 待删结点
    p->next = temp->next;
    temp->next->prev = p;             // ⚠️ 缺判空
    free(temp);
    return 1;
}
```

⚠️ **易错点**：若删除的是**最后一个结点**，`temp->next` 为 NULL，`temp->next->prev` 会**空指针崩溃**，要先判空：

```c
    p->next = temp->next;
    if (temp->next != NULL)
        temp->next->prev = p;
    free(temp);
```

## 六、遍历 traverseList

```c
void traverseList(DNode *L) {
    DNode *p = L->next;
    while (p != NULL) {
        printf("%d ", p->data);
        p = p->next;
    }
    printf("\n");
}
```

## 七、相对单链表的优势

- **双向遍历**：找前驱 O(1)，不用从头走。
- **删除已知结点 p 本身 O(1)**：有 prev 指针可直接删（单链表删自身要 O(n)）。

## 八、复杂度

| 操作 | 双链表 |
|---|---|
| 按位 / 按值查找 | O(n) |
| 已知结点后插 | O(1) |
| 删除已知结点 | O(1) |

## 九、缺点

- 每个结点多一个指针，**存储密度更低**。
