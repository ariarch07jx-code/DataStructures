# 1.2 单链表 (Singly Linked List)

结点之间用 `next` 指针串起来，逻辑上相邻的元素**物理上不必相邻**。代码里采用**带头结点**的单链表。

## 一、结点结构

```c
typedef int ElemType;

typedef struct node {
    ElemType data;        // 数据域
    struct node *next;    // 指针域，指向后继
} Node;
```

## 二、头指针 vs 头结点（易错点）

- **头指针**：指向链表**第一个结点**的指针（必须有，否则找不到链表）。
- **头结点**：附加在首元结点之前的一个结点，data 通常不用，next 指向首元结点。
- 本代码用带头结点的写法：初始化时创建一个头结点，`head->data = 0; head->next = NULL;`。

| | 带头结点 | 不带头结点 |
|---|---|---|
| 空表判断 | `L->next == NULL` | `L == NULL` |
| 第一个结点的操作 | 与其它结点一致 | 需要特殊处理 |

- **建议统一用带头结点**：空表/非空表、首结点/其它结点处理统一，代码不易错。

## 三、初始化与建立链表

**初始化**（创建一个头结点）：

```c
Node* InitList() {
    Node *head = (Node*)malloc(sizeof(Node));
    head->data = 0;
    head->next = NULL;
    return head;
}
```

**头插法**（每次插到表头，结果与输入顺序**相反**）：

```c
void insertHead(Node *L, ElemType e) {
    Node *newNode = (Node*)malloc(sizeof(Node));
    newNode->data = e;
    newNode->next = L->next;
    L->next = newNode;
}
```

**尾插法**（每次插到表尾，结果与输入顺序**相同**）：

```c
void insertTail(Node *L, ElemType e) {
    Node *newNode = (Node*)malloc(sizeof(Node));
    newNode->data = e;
    newNode->next = NULL;

    Node *p = L;
    while (p->next != NULL)   // 找到尾结点
        p = p->next;
    p->next = newNode;
}
```

## 四、按位插入 insertElem

在第 pos（1 ≤ pos）位插入 e，先**遍历找到第 pos-1 个结点 p**，再插到 p 之后：

```c
int insertElem(Node *L, int pos, ElemType e) {
    if (pos < 1 || pos > MAXSIZE) {   // 位序非法
        printf("Position is invalid\n");
        return 0;
    }
    Node *newNode = (Node*)malloc(sizeof(Node));
    newNode->data = e;
    Node *p = L;
    for (int i = 1; i < pos; i++) {   // 找第 pos 个的前驱 p
        if (p->next == NULL) {        // 越界
            printf("Position is invalid\n");
            free(newNode);
            return 0;
        }
        p = p->next;
    }
    newNode->next = p->next;
    p->next = newNode;
    return 1;
}
```

> 已知结点 p 时，在 p 之后插入 s 是 O(1)：先 `s->next = p->next;` 再 `p->next = s;`（两句顺序不能反）。

## 五、按位删除 deleteElem

删除第 pos 位元素，先遍历找到前驱 p，再删掉 p->next：

```c
int deleteElem(Node *L, int pos) {
    if (pos < 1 || pos > MAXSIZE) {
        printf("Position is invalid\n");
        return 0;
    }
    Node *p = L;
    for (int i = 1; i < pos; i++) {   // 找第 pos 个的前驱 p
        if (p->next == NULL) {
            printf("Position is invalid\n");
            return 0;
        }
        p = p->next;
    }
    Node *temp = p->next;             // 待删结点
    p->next = temp->next;
    free(temp);
    return 1;
}
```

## 六、查找

**按值查找 searchElem**：遍历比较，找到返回结点指针，否则返回 NULL：

```c
Node* searchElem(Node *L, ElemType e) {
    Node *p = L->next;
    while (p != NULL) {
        if (p->data == e)
            return p;
        p = p->next;
    }
    printf("Element not found\n");
    return NULL;
}
```

**查找倒数第 k 个 searchKthElem（快慢指针）**：快指针 q 先走 k 步，再让 p、q 同步走，q 到 NULL 时 p 即倒数第 k 个：

```c
Node* searchKthElem(Node *L, int k) {
    if (k < 1 || k > MAXSIZE) {
        printf("Position is invalid\n");
        return NULL;
    }
    Node *p = L->next;          // 慢指针
    Node *q = L->next;          // 快指针
    for (int i = 0; i < k; i++) {
        if (q == NULL) {        // 不足 k 个结点
            printf("Position is invalid\n");
            return NULL;
        }
        q = q->next;
    }
    while (q != NULL) {
        p = p->next;
        q = q->next;
    }
    return p;
}
```

## 七、反转链表 reverseList

用三个指针 prev、curr、nextNode 逐个反转 `next` 指向，最后让头结点指向新表头：

```c
Node* reverseList(Node *L) {
    Node *prev = NULL;
    Node *curr = L->next;
    while (curr != NULL) {
        Node *nextNode = curr->next;   // 暂存后继
        curr->next = prev;             // 反转
        prev = curr;
        curr = nextNode;
    }
    L->next = prev;                    // 头结点接新表头
    return L;
}
```

## 八、释放链表 freeList

逐个释放所有结点（含头结点）：

```c
void freeList(Node *L) {
    Node *p = L;
    while (p != NULL) {
        Node *temp = p;
        p = p->next;
        free(temp);
    }
}
```

## 九、补充：前插与删除自身（教材经典，代码未实现）

单链表只有 next，找前驱要 O(n)，可用**偷梁换柱法**达到 O(1)：

- **前插**：把 s 插到 p 之后，再交换 `s->data` 与 `p->data`。
- **删除 p 本身**：用后继 q 的数据覆盖 p，再删 q：
  ```c
  q = p->next;
  p->data = q->data;
  p->next = q->next;
  free(q);
  ```
  ⚠️ 若 p 是**最后一个结点**（q == NULL），此法失效，只能遍历找前驱 O(n)。

## 十、优缺点

**优点**：插入/删除灵活（已知结点 O(1)）；不需要连续空间；表长可动态增长。

**缺点**：不能随机存取（按位查找 O(n)）；存储密度低（多了指针域）。
