# 1.2 队列 (Queue)

队列（Queue）是只允许在**一端（队尾）插入、另一端（队头）删除**的线性表，遵循 **FIFO（先进先出）** 原则。

## 一、基本概念

- **队头 (front)**：允许删除的一端。
- **队尾 (rear)**：允许插入的一端。
- **入队 / 进队**：在队尾插入元素。
- **出队 / 出列**：删除队头元素。
- **取队头 (getHead)**：读取队头元素但**不删除**。

## 二、存储结构（三种实现）

| | 顺序队列 `SeqQueue.c` | 链式队列 `LinkedQueue.c` | 循环队列 `CirQueue.c` |
|---|---|---|---|
| 实现 | 数组 + front/rear | 头结点 + front/rear 指针 | 数组 + 取模循环 |
| 判满 | 有「假溢出」，需搬数据 | 不需要 | `(rear+1)%MAXSIZE == front` |
| 空间 | 固定 | 动态 | 固定，牺牲 1 个单元 |

## 三、顺序队列 (SeqQueue.c)

### 存储结构与 front/rear 含义

```c
#define MAXSIZE 100

typedef int ElemType;

typedef struct queue {
    ElemType data[MAXSIZE];
    int front;   // 队头下标
    int rear;    // 队尾下标（指向下一个待插入位置）
} Queue;
```

- `front` 指向**队头元素**，`rear` 指向**队尾元素的后一个位置**（待插入位）。
- 判空：`front == rear`。
- 初始化 `front = rear = 0`。

### 基本操作

```c
// 初始化
void initQueue(Queue *Q) {
    Q->front = 0;
    Q->rear = 0;
}

// 判空
int IsEmpty(Queue *Q) {
    if (Q->front == Q->rear) {
        printf("Queue is empty.\n");
        return 1;
    }
    return 0;
}

// 入队：先判满（假溢出则搬数据），再 rear++ 放入
int enqueue(Queue *Q, ElemType e) {
    if (Q->rear >= MAXSIZE) {
        if (!queueFull(Q))   // 真的满了才返回 0；否则只搬数据，继续入队
            return 0;
    }
    Q->data[Q->rear] = e;
    Q->rear++;
    return 1;
}

// 出队：先判空，再取队头后 front++
int dequeue(Queue *Q, ElemType *e) {
    if (Q->front == Q->rear) {
        printf("Queue is empty.\n");
        return 0;
    }
    *e = Q->data[Q->front];
    Q->front++;
    return 1;
}

// 取队头（不删除）
int getHead(Queue *Q, ElemType *e) {
    if (Q->front == Q->rear) {
        printf("Queue is empty.\n");
        return 0;
    }
    *e = Q->data[Q->front];
    return 1;
}
```

### 假溢出 & queueFull（核心）

顺序队列的经典问题：**rear 顶到 MAXSIZE，但 front 之前还有空位**（出队只让 front 后移、不回收空间），看起来满了其实没满，叫「假溢出」。

代码用 `queueFull` 把剩余元素**整体前移**，腾出队尾空间：

```c
int queueFull(Queue *Q) {
    if (Q->front > 0) {
        int step = Q->front;
        for (int i = Q->front; i < Q->rear; i++)   // 只搬 [front, rear-1]
            Q->data[i - step] = Q->data[i];
        Q->front = 0;
        Q->rear = Q->rear - step;
        return 1;
    } else {
        printf("Queue is really full!\n");
        return 0;
    }
}
```

> 注意：搬运循环用 `i < Q->rear`（不是 `i <= Q->rear`）。`rear` 指向「待插入位」，`rear` 本身不是有效元素，写成 `i <= rear` 会多读一个越界下标。

```c
for (int i = Q->front; i < Q->rear; i++)
    Q->data[i - Q->front] = Q->data[i];
```

## 四、链式队列 (LinkedQueue.c)

### 存储结构（带头结点）

```c
typedef struct qnode {
    ElemType data;
    struct qnode *next;
} QNode;

typedef struct queue {
    QNode *front;   // 队头指针（指向头结点）
    QNode *rear;    // 队尾指针（指向队尾结点）
} Queue;
```

- 带头结点：`front` 指向头结点，`rear` 指向队尾结点。
- 判空：`front->next == NULL`（或 `front == rear`）。
- 链式队列**不用判满**。

### 基本操作

```c
// 初始化（创建头结点，front=rear=头结点）
Queue* initQueue() {
    Queue *q = (Queue*)malloc(sizeof(Queue));
    QNode *node = (QNode*)malloc(sizeof(QNode));
    node->data = 0;
    node->next = NULL;
    q->front = node;
    q->rear = node;
    return q;
}

// 判空
int IsEmpty(Queue *Q) {
    if (Q->front->next == NULL) {
        printf("Queue is empty.\n");
        return 1;
    }
    return 0;
}

// 入队 = 尾插法
int enqueue(Queue *Q, ElemType e) {
    QNode *p = (QNode*)malloc(sizeof(QNode));
    p->data = e;
    p->next = NULL;
    Q->rear->next = p;   // 接到队尾
    Q->rear = p;         // 更新队尾指针
    return 1;
}

// 出队 = 删除头结点后的第一个结点
int dequeue(Queue *Q, ElemType *e) {
    if (Q->front->next == NULL) {
        printf("Queue is empty.\n");
        return 0;
    }
    QNode *q = Q->front->next;   // 队头元素
    *e = q->data;
    Q->front->next = q->next;    // 头结点越过它
    if (Q->rear == q)            // 若删的是最后一个元素，rear 回退到头结点
        Q->rear = Q->front;
    free(q);
    return 1;
}

// 取队头（不删除）
int getHead(Queue *Q, ElemType *e) {
    if (Q->front->next == NULL) {
        printf("Queue is empty.\n");
        return 0;
    }
    *e = Q->front->next->data;
    return 1;
}
```

### 易错点

- 入队是**尾插**、出队是**删首元结点**，别弄反。
- 删除**最后一个元素**时，要把 `rear` 回退到头结点（`if (Q->rear == q)` 那一步），否则 `rear` 悬空。
- 出队要 `free(q)`，防内存泄漏。

## 五、循环队列 (CirQueue.c)

### 思路

把数组看成**环**：`front`、`rear` 前进时用 `(x + 1) % MAXSIZE` 取模回绕，避免顺序队列的「假溢出」。

### 基本操作

```c
// 初始化
void initQueue(Queue *Q) {
    Q->front = 0;
    Q->rear = 0;
}

// 入队：先判满，再放入并 rear 循环 +1
int enqueue(Queue *Q, ElemType e) {
    if ((Q->rear + 1) % MAXSIZE == Q->front) {   // 队满
        printf("Queue is full.\n");
        return 0;
    }
    Q->data[Q->rear] = e;
    Q->rear = (Q->rear + 1) % MAXSIZE;
    return 1;
}

// 出队：先判空，再取队头并 front 循环 +1
int dequeue(Queue *Q, ElemType *e) {
    if (Q->rear == Q->front) {                   // 队空
        printf("Queue is empty.\n");
        return 0;
    }
    *e = Q->data[Q->front];
    Q->front = (Q->front + 1) % MAXSIZE;
    return 1;
}

// 取队头（不删除）
int getHead(Queue *Q, ElemType *e) {
    if (Q->front == Q->rear) {
        printf("Queue is empty.\n");
        return 0;
    }
    *e = Q->data[Q->front];
    return 1;
}
```

### 队空 / 队满判定（易错点）

- 队空：`front == rear`。
- 队满：`(rear + 1) % MAXSIZE == front`。
- **为什么队满要 `(rear+1)%MAXSIZE == front`**：如果不牺牲一个单元，队空和队满都是 `front == rear`，无法区分。所以循环队列**最多装 MAXSIZE-1 个元素**，留一个空位专门判满。

> 代码里注释把「最多装 MAXSIZE-1 个」当成 bug，其实**这是循环队列的标准做法**，不是 bug。

> 工程版实现见 [`src/cirqueue/`](src/cirqueue/)：拆成 `.h/.c`、只读参数加 `const`、补了 `is_full` 和 `size`，并带 `assert` 边界测试，可作为后续所有结构的样板。

## 六、复杂度速查

| 操作 | 顺序队列 | 链式队列 | 循环队列 |
|---|---|---|---|
| 入队 | O(1)（搬数据时 O(n)） | O(1) | O(1) |
| 出队 | O(1) | O(1) | O(1) |
| 取队头 | O(1) | O(1) | O(1) |
| 判空 | O(1) | O(1) | O(1) |

## 七、小结

- 顺序队列有**假溢出**，靠 `queueFull` 搬数据解决。
- 链式队列最灵活，不判满、不搬数据，但要处理删除最后一个元素时 `rear` 回退。
- 循环队列用**取模 + 牺牲一个单元**优雅解决假溢出，是顺序队列的升级版。
- 三个队列文件统一用 `enqueue` 命名入队操作。
