# 1.1 栈 (Stack)

栈（Stack）是只允许在**一端**进行插入和删除的**线性表**，遵循 **LIFO（后进先出）** 原则。

## 一、基本概念

- **栈顶 (top)**：允许插入 / 删除的一端。
- **栈底 (bottom)**：另一端，固定不动。
- **入栈 / 压栈 (push)**：在栈顶插入元素。
- **出栈 / 弹栈 (pop)**：删除栈顶元素。
- **取栈顶 (getTop)**：读取栈顶元素但**不删除**。

## 二、存储结构

栈有两种实现，代码里都写了：

| | 顺序栈 `SeqStack.c` | 链栈 `LinkedStack.c` |
|---|---|---|
| 实现 | 数组 + top 指针 | 单链表，**表头作栈顶** |
| 判满 | 需要（`top == MAXSIZE-1`） | 不需要 |
| 空间 | 固定容量 | 动态增长 |

## 三、顺序栈 (SeqStack.c)

### 存储结构

```c
#define MAXSIZE 100

typedef int ElemType;

typedef struct stack {
    ElemType data[MAXSIZE];  // 存储元素
    int top;                 // 栈顶指针
} Stack;
```

### top 指针的含义（易错点）

- `top = -1`：空栈（初始化时置 -1）。
- `top` **指向当前栈顶元素**的下标。
- 元素个数 = `top + 1`。
- 栈满：`top == MAXSIZE - 1`。

> 教材里另一种写法是 `top = 0` 表示 top 指向「下一个待插入位置」，判空判满和入栈顺序都不同。本代码统一用 **top = -1**，别混。

### 基本操作

```c
// 初始化
void initstack(Stack *s) {
    s->top = -1;
}

// 判空
int IsEmpty(Stack *s) {
    if (s->top == -1) {
        printf("Empty.\n");
        return 1;
    }
    return 0;
}

// 入栈：先判满，再 top++ 后放入
int push(Stack *s, ElemType e) {
    if (s->top >= MAXSIZE - 1) {   // 栈满
        printf("Stack is full.\n");
        return 0;
    }
    s->top++;
    s->data[s->top] = e;
    return 1;
}

// 出栈：先判空，再取出后 top--
int pop(Stack *s, ElemType *e) {
    if (s->top == -1) {            // 栈空
        printf("Stack is empty.\n");
        return 0;
    }
    *e = s->data[s->top];
    s->top--;
    return 1;
}

// 取栈顶（不删除）
int getTop(Stack *s, ElemType *e) {
    if (s->top == -1) {
        printf("Stack is empty.\n");
        return 0;
    }
    *e = s->data[s->top];
    return 1;
}
```

- 代码里还有一段**动态分配**的注释版本：`data` 改成 `ElemType *`，初始化时 `malloc` 分配，结构相同。元素个数不确定、怕浪费空间时用动态版。

## 四、链栈 (LinkedStack.c)

### 结点结构（带头结点）

```c
typedef struct stack {
    ElemType data;
    struct stack *next;
} Stack;
```

- 代码注释：**头结点的下一个结点是栈顶，尾结点是栈底**。
- 所有操作都在**表头（头结点之后）**进行，因为表头就是栈顶，push/pop 都是 O(1)，且**不需要判满**。

### 基本操作

```c
// 初始化（创建头结点）
Stack* initStack() {
    Stack *s = (Stack*)malloc(sizeof(Stack));
    s->data = 0;
    s->next = NULL;
    return s;
}

// 判空：头结点后没有元素
int isEmpty(Stack *s) {
    if (s->next == NULL) {
        printf("Stack is empty.\n");
        return 1;
    }
    return 0;
}

// 入栈 = 头插法
int push(Stack *s, ElemType e) {
    Stack *p = (Stack*)malloc(sizeof(Stack));
    p->data = e;
    p->next = s->next;
    s->next = p;
    return 1;
}

// 出栈 = 删除首元结点
int pop(Stack *s, ElemType *e) {
    if (s->next == NULL) {
        printf("Stack is empty.\n");
        return 0;
    }
    *e = s->next->data;
    Stack *q = s->next;
    s->next = s->next->next;
    free(q);                 // ⚠️ 要释放被删结点，防止内存泄漏
    return 1;
}

// 取栈顶（不删除）
int getTop(Stack *s, ElemType *e) {
    if (s->next == NULL) {
        printf("Stack is empty.\n");
        return 0;
    }
    *e = s->next->data;
    return 1;
}
```

### 易错点

- 链栈**不用判满**，空间按需分配。
- 出栈必须 `free(q)`，否则结点泄漏。
- 链栈的栈顶在头结点之后，所以 **push 就是头插、pop 就是删首元结点**，和单链表第一章的头插/删除一致。

## 五、复杂度速查

| 操作 | 顺序栈 | 链栈 |
|---|---|---|
| 入栈 push | O(1) | O(1) |
| 出栈 pop | O(1) | O(1) |
| 取栈顶 getTop | O(1) | O(1) |
| 判空 | O(1) | O(1) |

## 六、常见应用（了解）

- **括号匹配**：遇左括号入栈，遇右括号出栈比较。
- **表达式求值**：中缀转后缀、后缀求值都用栈。
- **递归**：函数调用栈，递归的本质就是栈。
- **深度优先搜索 (DFS)**、浏览器的前进/后退等。

## 七、小提醒

两个文件的函数命名风格不一致（`initstack` / `IsEmpty` vs `initStack` / `isEmpty`），建议统一成一种，例如都改成 `initStack` / `isEmpty`，代码更整洁。
